# Microcontrollers-EPFL-project
Binome project made during semester - Casual Radar system
During my second year at EPFL, as part of a microcontroller course, a classmate and I had to complete a mini-project using various hardware components.
We chose the SG90 servo motor and the HC-SR04 to make a simple Radar system. 
We had to program it in assembly; you can find the complete explanation in Manual pdf file.
